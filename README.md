# Gamefa Bale News Bot

ربات اخبار گیمفا برای بله.

- لینک gamefa.com را دریافت می‌کند.
- عنوان، تصویر شاخص و دقیقاً دو پاراگراف واقعی مقاله را استخراج می‌کند.
- عکس و متن را در یک پیام می‌فرستد.
- بدون OpenAI و بدون بازنویسی.
- در صورت قطع اتصال به API بله، به‌صورت خودکار Retry می‌کند.
