# Gamefa Bale News Bot

ربات دستی اخبار گیمفا برای بله.

لینک یک خبر از gamefa.com را برای ربات بفرستید. ربات:
- عنوان مقاله را استخراج می‌کند.
- تصویر شاخص را استخراج می‌کند.
- دقیقاً دو پاراگراف واقعی اول مقاله را استفاده می‌کند.
- هیچ بازنویسی یا خلاصه‌سازی AI انجام نمی‌دهد.
- عکس و متن را در یک پیام برای ادمین ارسال می‌کند.

## نصب
pip install -r requirements.txt

## Railway
Procfile:
worker: python bot.py

`.env.example` را به `.env` تبدیل کنید و BALE_TOKEN و ADMIN_IDS را وارد کنید.
